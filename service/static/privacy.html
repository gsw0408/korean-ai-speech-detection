2. 처리하는 개인정보의 항목, 목적, 보유 기간

구분항목목적보유 기간
음성 분석 (필수, 분석 동의 시)업로드한 음성 파일AI 합성 흔적 분석 결과 제공메모리와 임시 공간에서만 처리하고 분석이 끝나면 삭제합니다. 저장하지 않습니다.
음성 데이터 제공 시연 (선택, 별도 동의 시)동의 시각, 분석 결과 구분, 모델 버전, 동의 문구 버전, 철회 코드의 해시값동의 및 철회 절차 시연30일이 지나면 자동 삭제. 프로젝트 종료 시 전부 삭제. 음성 파일과 파일 해시는 저장하지 않습니다.
요청 횟수 제한접속 IP 주소과도한 요청 차단프록시 서버 메모리에서만 최대 1시간 사용하고 파일이나 로그에 기록하지 않습니다.
서비스 운영 기록요청 번호, 음성 길이, 분석 결과 구분, 처리 시간, 모델 버전, 저장 개수·용량장애 확인과 용량 관리서버 운영 로그로 보관하며, 서비스 컨테이너를 교체하거나 프로젝트가 끝나면 삭제합니다. IP 주소, 파일 이름, 철회 코드는 기록하지 않습니다.

이름, 연락처, 계정 정보는 받지 않습니다.

  • 파일을 선택해도 “음성 분석하기”를 누르기 전에는 서버로 전송되지 않습니다. 선택한 파일의 재생은 브라우저 안에서만 이루어집니다.
  • 쿠키, 광고·방문 분석 도구, 외부 글꼴이나 외부 스크립트를 사용하지 않습니다. 개인정보를 자동으로 수집하는 장치는 위 표의 요청 횟수 제한(메모리, 최대 1시간) 외에는 운영하지 않습니다.
  • 결과 화면의 “재현 정보”에 표시되는 요청 번호는 무작위 값으로, 오류 확인용이며 개인을 식별하지 않습니다.

[검토 필요] 분석 처리의 법적 근거를 동의(법 제15조 제1항 제1호)로 둘지 다른 근거로 둘지. 분석을 위해 일시 처리하는 음성을 민감정보·생체인식정보(법 제23조, 시행령 제18조)로 보아야 하는지 — 서비스는 음성으로 특정 개인을 알아보는 처리를 하지 않으며 음성 파일을 저장하지 않습니다.

3. 제3자 제공과 처리 위탁

  • 개인정보를 제3자에게 제공하지 않습니다.
  • 서비스와 동의 기록은 Amazon Web Services(AWS) 서울 리전(ap-northeast-2)의 서버와 암호화된 디스크에서 처리·보관합니다. 운영자가 직접 서버를 관리하며, 클라우드 사업자가 내용을 이용하도록 맡기지 않습니다.
  • 개인정보를 국외로 이전하지 않습니다. 저장 위치는 대한민국(서울 리전)입니다.

[검토 필요] 클라우드 인프라 이용이 처리 위탁(법 제26조)에 해당하는지, 해당한다면 수탁자 명칭(【수탁자 명칭】)과 위탁 업무를 공개해야 하는지. 해외 법인 운영 클라우드의 국내 리전 이용이 국외 이전(법 제28조의8, 시행령 제31조 제1항 제2호)에 해당하지 않는지.

4. 보관 기간과 파기 절차·방법

  • 음성 데이터 제공을 선택하면 분석이 끝난 뒤 음성 사본이 메모리에만 최대 15분 있으며, 확정하거나 취소하면 바로 삭제됩니다. 음성 파일은 디스크에 저장하지 않습니다.
  • 동의 기록은 30일이 지나면 자동 삭제합니다. 삭제 작업은 서비스가 실행 중일 때 1시간마다 실행되며, 서비스가 중지된 동안 기한이 지난 기록은 서비스를 다시 시작할 때 바로 삭제합니다.
  • 파기 방법: 동의 기록은 데이터베이스에서 행을 삭제한 뒤 데이터베이스 파일을 재구성(VACUUM)하여 남은 내용을 지웁니다. 분석용 음성은 메모리 기반 임시 공간에서 처리 직후 삭제됩니다.
  • 프로젝트가 끝나면 남은 기간과 관계없이 모든 동의 기록을 삭제합니다. 백업이나 스냅숏은 만들지 않습니다.
  • 삭제한 기록은 서비스와 관리 저장소(서버 디스크, 클라우드 저장소)에서 다시 열람하거나 복구할 수 없게 처리합니다. 다만 저장 장치의 물리적 완전 소거까지 보장하지는 않습니다.
  • 법령에 따라 보존해야 하는 개인정보는 없습니다.

5. 정보주체의 권리와 행사 방법

  • 정보주체는 개인정보의 열람, 정정·삭제, 처리정지, 동의 철회를 요구할 수 있으며, 법정대리인이나 위임을 받은 사람을 통해서도 요구할 수 있습니다.
  • 음성 데이터 제공은 선택 사항입니다. 동의하지 않아도 음성 분석은 그대로 이용할 수 있습니다.
  • 제공을 확정하면 한 번만 표시되는 철회 코드를 드립니다. 메인 화면의 “제공 동의 철회”에 코드를 입력하면 해당 동의 기록이 즉시 삭제됩니다. 제공 기능을 중지한 동안에도 철회는 가능합니다.
  • 이름이나 연락처를 받지 않으므로 코드를 잃어버리면 정보주체를 확인할 수 없어 개별 철회가 어렵습니다. 이 경우 동의 기록은 30일이 지나면 자동 삭제됩니다.
  • 그 밖의 문의나 권리 행사 요청: 【이메일 주소】

[검토 필요] 코드 없이 열람·삭제를 요청하는 경우의 처리 절차와 안내 문구, 처리 기한.

6. 만 14세 미만 아동

  • 서비스에는 법정대리인 동의를 확인하는 절차가 없으므로, 만 14세 미만은 음성 분석과 음성 데이터 제공을 이용할 수 없습니다.
  • 만 14세 미만은 음성 데이터 제공에 참여할 수 없습니다. 확정 화면에서 연령과 녹음 참여자 동의를 확인해야 동의가 기록됩니다.

[검토 필요] 자기 확인 방식이 법 제22조의2(아동의 개인정보 보호)에 충분한지, 법정대리인 동의 절차를 갖춰야 하는지.

7. 녹음 파일에 관한 주의

  • 녹음에 목소리가 담긴 모든 사람에게서 동의를 받은 음성만 제공할 수 있습니다.
  • 공개되지 않은 타인 간의 대화를 그 대화에 참여하지 않은 사람이 녹음하는 것은 통신비밀보호법으로 금지됩니다. 이렇게 녹음된 파일은 올리지 마세요.

[검토 필요] 타인·공인 음성의 분석 이용과 제공을 어떻게 안내·제한할지.

8. 자동화된 분석 결과에 대하여

  • 분석 결과는 AI 모델이 자동으로 계산한 참고용 지표이며, 확률이나 진위 판정이 아닙니다. 서비스는 이 결과로 이용자의 권리나 의무에 관한 결정을 내리지 않습니다.
  • 판단 방식은 결과 화면의 “어떻게 판단하나요?”와 “측정된 성능과 한계”에서 설명합니다. 추가 설명이 필요하면 위 연락처로 요청할 수 있습니다.

[검토 필요] 법 제37조의2(자동화된 결정에 대한 정보주체의 권리)의 적용 여부와 고지 문구.

9. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화합니다.
  • 동의 기록은 별도의 용량 제한 저장 공간에 서비스 계정만 읽을 수 있는 권한으로 보관하며, 공개 경로로 제공하지 않습니다.
  • 서버에는 원격 셸 접속 포트를 열지 않고, 클라우드 계정 권한으로만 관리합니다.
  • 철회 코드는 해시값으로만 저장합니다. 요청 횟수를 제한해 무차별 대입을 막습니다.
